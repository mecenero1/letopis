# Летопись — все даты истории России

Тренажёр для заучивания дат: 261 дата, карточки, тесты, контрольные, трекер и огонёк.
Автор: [@mecenero](https://t.me/mecenero) в Telegram.

## Как выложить на GitHub Pages

1. Создай репозиторий `letopis` (Public).
2. Add file → Upload files → загрузи все файлы из этой папки (кроме README можно не грузить).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://mecenero1.github.io/letopis/`.

## Если имя на GitHub не `mecenero` или репозиторий называется иначе

Замени адрес `https://mecenero1.github.io/letopis/` на свой в трёх файлах:

- `index.html` — в начале файла (canonical, og:url, og:image и блок ld+json);
- `robots.txt`;
- `sitemap.xml`.

## Чтобы сайт находили в Яндексе и Google

1. **Яндекс Вебмастер** (webmaster.yandex.ru): добавь сайт → выбери подтверждение через мета-тег → вставь его в `index.html` на место строки `yandex-verification` (убери комментарий вокруг) → загрузи файл заново → нажми «Проверить». Потом в разделе «Индексирование → Файлы Sitemap» добавь `https://ИМЯ.github.io/letopis/sitemap.xml`.
2. **Google Search Console** (search.google.com/search-console): тип ресурса «Префикс URL» → подтверждение через HTML-тег → вставь на место `google-site-verification` → «Подтвердить» → в разделе «Файлы Sitemap» добавь тот же адрес.
3. Делись ссылкой в Telegram, ВК и школьных чатах: ссылки с других сайтов помогают поиску сильнее всего.

## Как обновлять

Загрузи новый `index.html` в тот же репозиторий с заменой. Открытые у людей страницы подхватят обновление при следующем заходе с интернетом.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `icon.svg` | установка на телефон как приложение и иконки |
| `sw.js` | работа без интернета после первого захода |
| `og.png` | картинка-превью, когда ссылку присылают в Telegram и ВК |
| `robots.txt`, `sitemap.xml` | подсказки для поисковиков |
| `404.html` | страница «не найдено» с возвратом на главную |
| `.nojekyll` | GitHub отдаёт файлы как есть, без сборки |

Прогресс каждого человека хранится в его браузере. Перенести его на другое устройство можно в «Трекере»: «Резервная копия» → «Сохранить» и «Загрузить».
